# flow ドキュメント

Astro + Starlight の日本語ドキュメントです。リポジトリルートから実行します。

```sh
pnpm docs:generate
pnpm docs:dev
pnpm docs:check
pnpm docs:build
```

CLI の個別説明は `scripts/docs/cli-notes.mjs`、運用ガイドは `apps/docs/src/content/docs/` で編集します。詳しい更新手順は [開発・更新・リリース](src/content/docs/contributing/maintenance.md) を参照してください。
