## 保存先

| 保存先                                         | 内容                                                                                                                                   |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `.flow/WORKFLOW.md`                            | プロジェクトの Workflow 設定。                                                                                                         |
| `.flow/state/owned.json`                       | worktree、ペイン、タブ、エージェントの所有。再起動後も保持します。                                                                     |
| `.flow/state/locks/registry.json`              | slot や共有・排他資源の割当と待ち行列。                                                                                                |
| `.flow/state/issues.json`                      | Issue ディレクトリがまだない場合の状態。                                                                                               |
| `.flow/state/workflow-good.json`               | 最後に正常に読み込めた Workflow。通常操作は必要時にこの設定へフォールバックします。                                                    |
| `.flow/state/previews/assignment-<issue>.json` | アサインに使う本文の確認用。                                                                                                           |
| `.flow/run/`                                   | PID ロック、wake、watch のカーソル、`last-plan.json`、dry-run の一時ディレクトリ等。該当プロセスが停止していることを確認して扱います。 |
| `.flow/logs/<YYYY-MM-DD>/`                     | 本番 `events.ndjson` と dry-run `events.dry-run.ndjson`。日本時間の日付で分離。                                                        |
| `<Issue ディレクトリ>/flow/`                   | `state.json`、試行単位の結果、継続処理の情報。段階変更とともに移動します。                                                             |

旧レイアウトが残っている場合は CLI が移行します。移行先にも同名の記録がある場合は自動で上書きせずエラーにします。

## 環境変数

- `ISSUE_DIR` は同梱 Issue コマンドが使う格納先です。メインのチェックアウトのルートからの相対パスを設定します。別の worktree で実行した場合も、メインのチェックアウトのルートを基準にします。
- `ISSUE_STATUSES` は同梱コマンドの段階名を空白区切りで指定します。指定順はディレクトリ名の番号になります。一部の標準段階名を同梱の `push`・`status` が直接参照するため、変更時は呼び出しも見直します。
- `HERDR_PANE_ID` は Herdr が与えるペイン情報です。`workspace: none` の起動には Herdr 内の実行が必要です。
- `NO_COLOR` が環境にあれば ANSI 色を無効化します。`TERM=dumb` は色と端末リンクを無効化します。
- `PATH` から `gh`、Herdr 等を探します。CLI は同梱コマンドと現在の Node の位置を先頭に足し、`FLOW_TOOLS` に同梱ツールのパスを設定します。`FLOW_NODE`・`FLOW_MAIN` は補助スクリプトの内部呼び出しに渡します。
- GitHub の認証は `gh` の認証設定または対応する環境変数を使います。フック用の変数は [worktree 設定](/reference/worktree/)を参照します。

## エラーと終了ステータス

| 終了コード               | 意味                                                                                                     |
| ------------------------ | -------------------------------------------------------------------------------------------------------- |
| 0                        | 正常終了、ヘルプの表示、または監視ループの正常停止。Issue 単体の状態は表や JSON で確認します。           |
| 1                        | 構文エラー、必須値不足、設定や実行の例外など。CLI は診断と関連コマンドのヘルプを表示することがあります。 |
| 補助コマンドの終了コード | `flow issue` と `flow wt` は同梱スクリプトの終了コードを引き継ぎます。                                   |

`flow run` は個々の tick の例外を通知とログに残し、周期を継続します。`flow tick` や各行の状態も、終了コードと別に確認してください。[症状から調べる](/troubleshooting/)に具体的な診断をまとめています。
