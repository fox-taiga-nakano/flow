## flow のしくみ

flow は定期的に GitHub とローカルの状態を照合します。プロジェクトの `WORKFLOW.md` に書かれた条件から Step を選び、必要に応じて worktree と専用のペインを用意します。人が判断する箇所は Gate として設定します。
